# DeliverProof interface

Original minimal Next.js frontend. See ../../docs/INSTALL.md and
../../docs/VALIDATION-M2.md. The checked-in deployment manifest is null; no wallet
action works until an independently checked deployment is explicitly installed.
Run it from the repository root with `npm run next:dev`, or `npm run next:build` and `npm run next:start`.
No backend, cookies, key storage, automatic file upload or background polling.
